Interface web em modo de simulacao (com alunos de exemplo e tempo normal):
python servidor.py

A interface abre no navegador em http://127.0.0.1:8000.
Depois de entrar com o PIN, use "Ver registros de eventos" para abrir a pagina de registros.

Modo de producao (usa data/escola.db):
python servidor.py --producao

Para definir outro PIN do professor:
PIN_PROFESSOR=4321 python servidor.py

Para iniciar sem abrir o navegador automaticamente:
python servidor.py --sem-navegador

Alunos e turmas fixos:
Edite o arquivo turmas.py. Cada aluno deve ser informado como (ID_DO_SENSOR, "Nome"),
dentro da lista da turma correspondente. Os IDs precisam ser unicos entre todas as turmas.
Os nomes e IDs atuais sao ficticios. Antes de usar o sensor, substitua os nomes e grave
cada digital no sensor usando o ID numerico correspondente. Confirme tambem que o sensor
suporta a quantidade de digitais cadastradas.

Aplicacao de terminal, sem interface web:
python main.py

Sensor fisico na aplicacao de terminal:
SENSOR=real PORTA_SENSOR=/dev/ttyUSB0 python main.py
